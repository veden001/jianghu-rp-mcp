# 江湖棋局 · Jianghu RP MCP

一个**由桌游盘面驱动的双人即兴武侠 Roleplay 框架**。

它不需要独立 UI。玩家直接在支持 MCP 的聊天界面中游玩：AI 同时担任桌游主持人和第二名玩家，MCP 引擎负责硬规则，聊天负责角色扮演。

> 当前版本：v0.1.1 · 第一章「中原风起」

## 当前已实现

- 2 名玩家：人类 + AI
- 16 张身份卡：12 普通 + 4 特殊
- 自选 / 随机身份模式
- 特殊身份仅可随机获得
- 全员初始银两 30 两
- 第一章 36 格完整中原地图
  - 14 个双人 RP 江湖场景（6 个核心场景 + 7 个随机场景 + 1 个终幕）
  - 8 个轻事件
  - 6 个功能格
  - 4 个特殊地标
  - 4 个节奏格
- 1d6 掷骰与自动移动
- 银两与简单道具系统
- 核心场景经过即停，随机场景仅在准确落格时触发
- 4 个节奏格带可选的轻量互动钩子
- 功能格 A/B/C/D 选择
- 江湖场景自由互动 + 固定结算
- 第一名完成地图获得纯收藏品「洛阳牡丹花牌」
- 本地 JSON 自动存档

## 核心设计

**功能格：选择。**  
**江湖场景：表演。**  
**系统：收尾。**

AI 不负责决定硬规则，也不负责给角色扮演打分。引擎已经写好骰子、资源变化、通关条件和固定结算；AI 只负责主持、陪演和推进。

## 技术栈

- Node.js 20+
- TypeScript
- MCP TypeScript SDK v2 (`@modelcontextprotocol/server`)
- Zod v4

## 运行

```bash
npm install
npm run dev
```

用 MCP Inspector 调试：

```bash
npm run inspect
```

## MCP 工具

| Tool | 用途 |
| --- | --- |
| `game_help` | 读取主持规则与当前版本内容 |
| `new_game` | 创建新游戏、分配身份 |
| `roll` | 当前玩家掷骰并由引擎推进 |
| `game_action` | 功能格购买、场景结算、道具、重掷、仙人伪装 |
| `game_info` | 查询状态、身份池、道具、地图或主持规则 |

## 内容结构

```text
content/
├── identities.json
├── items.json
└── maps/
    └── zhongyuan.json
```

后续章节将直接追加：

```text
content/maps/saibei.json
content/maps/jiangnan.json
```

剧情与程序分离，因此可以在不修改核心引擎的情况下继续扩写地图。

## 第一章主线

古剑「照骨」现世。传闻剑身七十二道铭文指向一座失落武库，而照骨本身就是武库最后一道机关的钥匙。

一句荒唐的传言传遍江湖：

> 得照骨者，得天下。

所以天下人全来了。

第一章从洛阳开始，以照骨剑渡过黄河、进入塞外结束。
