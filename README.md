# 江湖棋局 · Jianghu RP MCP

一个**由桌游盘面驱动的双人即兴武侠 Roleplay 框架**。

它不需要独立 UI。玩家直接在支持 MCP 的聊天界面中游玩：AI 同时担任桌游主持人和第二名玩家，MCP 引擎负责硬规则，聊天负责角色扮演。

> 当前版本：v0.2.1 · 第一章「中原风起」+ 第二章「塞北逐剑」

## 当前已实现

- 2 名玩家：人类 + AI
- 16 张身份卡：12 普通 + 4 特殊
- 自选 / 随机身份模式
- 特殊身份仅可随机获得
- 全员初始银两 30 两
- 两张完整 36 格地图：中原、塞北
- 每章结构：14 个双人 RP 江湖场景、8 个轻事件、6 个功能格、4 个特殊地标、4 个节奏格
- 每章 6 个核心场景经过即停，7 个随机场景仅准确落格触发，终幕必触发
- 1d6 掷骰与自动移动
- 节奏格互动钩子、同格偶遇
- 银两、功能道具与互动收藏品系统
- 道具可使用、佩戴、赠送、定制与刻字
- 跨章保留身份、银两、收藏品和未使用道具
- 第一章完成后可通过 `start_next_chapter` 进入第二章
- 第一章纪念收藏品「洛阳牡丹花牌」；第二章纪念收藏品「塞北马铃」
- 本地 JSON 自动存档

## 核心设计

**功能格：选择。**  
**江湖场景：表演。**  
**系统：收尾。**

AI 不负责决定硬规则，也不负责给角色扮演打分。引擎已经写好骰子、资源变化、通关条件和固定结算；AI 只负责主持、陪演和推进。

互动道具遵循同一原则：它们可以改变“事情怎么发生”，但不能擅自改变“系统规定最后发生什么”。

## 剧情概览

百年前，江湖曾有女剑客**慕容镜**，年纪轻轻便败尽天下名家，世人敬称“剑仙”。她晚年归隐后再未现身，只留下随身佩剑「照骨」。

后世传言，照骨剑身七十二道铭文指向慕容镜留下的一座武库，而照骨本身就是最后一道机关的钥匙。

一句传闻随之传遍天下：

> 得照骨者，得天下。

第一章从洛阳夺剑开始。第二章一路追入塞北，而这场看似混乱的追逐开始显露出越来越多不合常理的痕迹。更多剧情请直接在游戏中发现。

## 第一章商店与江湖玩具

第一章有 6 个功能格：洛阳西市、百草堂、鬼市、山间酒肆、老铁匠铺、北路驿站。

除了传统功能道具，也出售纯粹为了角色互动存在的收藏品，例如傩面、金步摇、勾践尝过的胆、受潮麦丽素、变猪喷雾、神秘小册子、铁莲花簪与驿站卤蛋。

“亲密度↑”只是玩笑式系统提示，本游戏**没有亲密度数值**。

第二章的 6 个商店目前已具备基础功能商品，互动收藏品将在第二章试玩后继续补充。

## MCP 工具

| Tool | 用途 |
| --- | --- |
| `game_help` | 读取主持规则与当前版本内容 |
| `new_game` | 创建新游戏、分配身份 |
| `roll` | 当前玩家掷骰并由引擎推进 |
| `game_action` | 功能格购买、场景结算、跨章、道具使用/佩戴/赠送/定制、重掷、仙人伪装 |
| `game_info` | 查询状态、身份池、道具、指定章节地图或主持规则 |

### `game_action` 的互动道具动作

- `use_item`：使用功能道具或互动道具。上官昭容诗集需额外传 `chosenRoll: 1-6`。
- `wear_item`：佩戴或摘下可穿戴收藏品。
- `gift_item`：把一件已有道具赠给另一名玩家。
- `customize_item`：定制支持自定义的道具。
- `buy`：功能格购买。刻字服务需同时传 `targetItemId` 与 `customText`。
- `start_next_chapter`：当前章节完成后进入下一章。

### 章节切换

第一章终幕完成后，系统进入 `chapter_complete`。调用：

```text
game_action(action="start_next_chapter")
```

即可进入「第二章：塞北逐剑」。跨章时：

- 保留双方身份与伪装；
- 保留银两、收藏品、刻字/定制信息与未使用道具；
- 双方位置重置到第 1 格；
- 清除上一章未结算的临时移动/骰点效果。

## 内容结构

仓库按章节拆分。打开仓库即可从 `chapters/` 进入每一章；通用身份与跨章节功能道具单独保留。

```text
chapters/
├── chapter-1-zhongyuan/
│   ├── README.md
│   ├── map.json
│   └── items.json
├── chapter-2-saibei/
│   ├── README.md
│   ├── map.json
│   └── items.json
└── chapter-3-jiangnan/
    └── README.md        # 第三章规划中

content/
├── identities.json
└── common-items.json

src/                    # 通用 MCP / 游戏引擎
tests/                  # 引擎测试
examples/               # MCP 配置示例
```

每章的剧情地图、章节专属收藏品和互动商品放在自己的目录里；`content/` 只保留跨章节共享内容。这样后续扩写第二章商店或第三章时，不需要把三章内容混在同一个大型 JSON 中。
