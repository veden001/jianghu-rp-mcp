# 江湖棋局 · Jianghu RP MCP

一个**由桌游盘面驱动的双人即兴武侠 Roleplay 框架**。

它不需要独立 UI。玩家直接在支持 MCP 的聊天界面中游玩：AI 同时担任桌游主持人和第二名玩家，MCP 引擎负责硬规则，聊天负责角色扮演。

> 当前版本：v0.1.2 · 第一章「中原风起」

## 当前已实现

- 2 名玩家：人类 + AI
- 16 张身份卡：12 普通 + 4 特殊
- 自选 / 随机身份模式
- 特殊身份仅可随机获得
- 全员初始银两 30 两
- 第一章 36 格完整中原地图
  - 14 个双人 RP 江湖场景（6 个核心场景 + 7 个随机场景 + 1 个终幕）
  - 8 个轻事件
  - 6 个功能格
  - 4 个特殊地标
  - 4 个节奏格
- 1d6 掷骰与自动移动
- 核心场景经过即停，随机场景仅在准确落格时触发
- 节奏格带可选的轻量互动钩子
- 两名玩家落在同一格时可触发轻量“同格偶遇”
- 银两、功能道具与互动收藏品系统
- 道具可使用、佩戴、赠送与定制
- 老铁匠铺支持永久刻字
- 互动道具只改变 RP 过程，不改变固定结算
- 第一名完成地图获得纯收藏品「洛阳牡丹花牌」
- 本地 JSON 自动存档

## 核心设计

**功能格：选择。**  
**江湖场景：表演。**  
**系统：收尾。**

AI 不负责决定硬规则，也不负责给角色扮演打分。引擎已经写好骰子、资源变化、通关条件和固定结算；AI 只负责主持、陪演和推进。

互动道具遵循同一原则：它们可以让“事情怎么发生”变得更离谱、更有角色感，但不能擅自改变“系统规定最后发生什么”。

## 第一章的商店气质

第一章目前有 6 个功能格：洛阳西市、百草堂、鬼市、山间酒肆、老铁匠铺、北路驿站。

除了传统功能道具，也会出售纯粹为了角色互动存在的收藏品，例如：

- 傩面：戴上很威风。
- 金步摇：可以自己戴，也可以送人。
- 勾践尝过的胆：舔一口，痛苦面具。
- 变猪喷雾：把搭档变成粉色迷你猪半个时辰。
- 神秘小册子：摊主疯狂暗示，内容却完全不是你想的那种。
- 铁莲花簪：粗糙但结实，可以别头发，也可以捅人。
- 驿站食堂卤蛋：烫，但是好吃。

“亲密度↑”只是玩笑式系统提示，本游戏**没有亲密度数值**。

## MCP 工具

| Tool | 用途 |
| --- | --- |
| `game_help` | 读取主持规则与当前版本内容 |
| `new_game` | 创建新游戏、分配身份 |
| `roll` | 当前玩家掷骰并由引擎推进 |
| `game_action` | 功能格购买、场景结算、道具使用/佩戴/赠送/定制、重掷、仙人伪装 |
| `game_info` | 查询状态、身份池、道具、地图或主持规则 |

### `game_action` 的互动道具动作

- `use_item`：使用功能道具或互动道具。上官昭容诗集需额外传 `chosenRoll: 1-6`。
- `wear_item`：佩戴或摘下可穿戴收藏品。
- `gift_item`：把一件已有道具赠给另一名玩家。
- `customize_item`：定制支持自定义的道具，例如为变猪喷雾额外支付 3 两定制动物款。
- `buy`：功能格购买。老铁匠铺的刻字服务需同时传 `targetItemId` 与 `customText`。

## 内容结构

```text
content/
├── identities.json
├── items.json
└── maps/
    └── zhongyuan.json
```

后续章节将直接追加：

```text
content/maps/saibei.json
content/maps/jiangnan.json
```

剧情与程序分离，因此可以在不修改核心引擎的情况下继续扩写地图。

## 第一章主线

古剑「照骨」现世。传闻剑身七十二道铭文指向一座失落武库，而照骨本身就是武库最后一道机关的钥匙。

一句荒唐的传言传遍江湖：

> 得照骨者，得天下。

所以天下人全来了。

第一章从洛阳开始，以照骨剑渡过黄河、进入塞外结束。
