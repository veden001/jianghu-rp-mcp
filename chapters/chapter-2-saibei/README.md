# 第二章：塞北逐剑

**状态：可试玩**  
**主题：追剑 / 疑局**  
**地图：36 格**  
**章节收藏品：塞北马铃**

照骨剑一夜过黄河。两名玩家追入塞北，却逐渐发现：消息总比剑更快，路线像是早已排好，有人在刻意让这场争夺持续下去。

本目录：

- `map.json`：第二章完整 36 格地图、场景、轻事件、地标、节奏格与商店。
- `items.json`：第二章专属收藏品、互动商品与章节纪念品。现已加入长梢弓、花木兰马具组合包、骑马肖像画、孙思邈手札、仓鼠跑轮、飞天蟑螂模型、猎户手套、小铁马等塞北旅行小垃圾。

通用身份与跨章节功能道具位于仓库根目录的 `content/`。
